# Titanic EDA & Cricket Sports Analysis

A compact data-science portfolio repository containing two notebook-based analysis projects and the presentation used to summarize the work.

## Projects

### Titanic Dataset EDA
**Notebook:** `Titanic Dataset EDA.ipynb`

Exploratory analysis of passenger data using Python data-analysis and visualization tools.

### Cricket Sports Data Analysis
**Notebook:** `Sports Data Analysis.ipynb`

Ball-by-ball cricket analysis using delivery-level data, including batting, bowling, runs, dismissals, and match context.

